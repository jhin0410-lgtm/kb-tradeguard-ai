# KB TradeGuard AI 사용성 검증 프로토콜

## 목적

공개 합성 데모에서 사용자가 다음 두 가지를 빠르게 찾을 수 있는지 검증한다.

1. 거래에서 가장 먼저 확인해야 할 위험
2. 가장 먼저 수행해야 할 실행 행동

이 검증은 모델 정확도, 실제 은행 적격성, 거래 승인 가능성 또는 금융성과를 측정하지 않는다.

## 대상

최소 5명 권장:

- 수출입 또는 무역 업무 경험자 1명 이상
- 금융·보험·보증 관련 경험자 1명 이상
- 관련 경험이 없는 일반 사용자 2명 이상
- 모바일 사용자 1명 이상

참가자의 이름, 연락처, 회사명, 실제 거래정보는 수집하지 않는다. `P01` 같은 익명 코드만 사용한다.

## 실행

1. 공개 데모 URL 뒤에 `?study=true`를 붙인다.
2. 참가자에게 별도 설명 없이 다음 과제를 제시한다.
   - “이 거래에서 가장 먼저 볼 위험과 첫 번째 실행 행동을 찾으세요.”
3. `과제 시작`을 누른 뒤 사용자가 화면을 탐색하게 한다.
4. 사용자가 위험과 행동을 선택하고 `과제 완료`를 누른다.
5. 결과 JSON을 저장한다.
6. 아래 사후 질문을 구두로 묻되 개인식별정보는 기록하지 않는다.

## 사후 질문

- 가장 먼저 이해된 정보는 무엇이었는가?
- 이해하기 어려운 용어는 무엇이었는가?
- 불필요하거나 반복적으로 느껴진 화면은 무엇인가?
- 이 결과를 은행 상담 전에 사용할 의향이 있는가? 그 이유는 무엇인가?
- 실제 상담으로 넘어가기 전에 추가로 보고 싶은 정보는 무엇인가?

## 핵심 지표

| 지표 | 계산 | 권장 목표 |
|---|---|---:|
| Task success | 위험과 행동을 모두 정답으로 선택한 비율 | 80% 이상 |
| Median completion time | 참가자별 완료시간의 중앙값 | 90초 이하 |
| Risk discovery | 최상위 위험 정답률 | 80% 이상 |
| Action discovery | 첫 행동 정답률 | 80% 이상 |
| Terminology issue count | 이해하기 어렵다고 언급된 고유 용어 수 | 감소 추적 |
| Consultation intent | 상담 전 사용 의향 응답 비율 | 참고지표 |

목표치는 공모전용 내부 사용성 기준이며 외부 서비스 성과나 통계적 유의성을 주장하지 않는다.

## 결과 집계

각 JSON에서 다음 필드를 집계한다.

- `elapsed_seconds`
- `risk_correct`
- `action_correct`
- `task_success`

5명 미만의 결과는 정성적 파일럿으로만 표시한다. 참가자 모집이 완료되지 않은 상태에서 “사용성 검증 완료” 또는 “업무시간 절감”을 주장하지 않는다.

## 개인정보 경계

- 이름, 이메일, 전화번호 수집 금지
- 회사명과 실제 수출입 거래 입력 금지
- 고객문서 업로드 금지
- 브라우저 세션 밖 자동 전송 없음
- 저장한 JSON은 참가자 코드만 포함
