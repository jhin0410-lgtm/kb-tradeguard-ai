# Privacy notice

The default deterministic demo path makes no external AI request. Uploaded
files are handled in process memory and are not intentionally persisted or
included in audit exports.

Configured structured advisory mode transmits the user’s question and
structured deterministic tool outputs to the configured provider. Optional
document extraction transmits relevant document content. Do not enable these
paths for confidential or personal information without appropriate consent,
retention review, provider terms, and organizational approval.

The manual provider smoke test uses bundled synthetic data and writes only a
redacted evidence transcript. It never writes API keys or uploaded documents.
