# KB TradeGuard AI 사용성 검증 프로토콜

## 목적

공개 데모 사용자가 3분 안에 거래 판정, 핵심 위험, 다음 행동, 금융지원 후보와 판단 근거를 찾을 수 있는지 확인합니다.

## 참여자 구성

최소 5명을 권장합니다.

- 중소기업 수출입 실무자 또는 경험자 2명
- 금융·무역·보험 관련 학습자 또는 실무자 2명
- 비전문 사용자 1명

실제 결과를 임의 생성하지 않습니다. 참여자는 이름·연락처 대신 `P01`과 같은 익명 ID만 사용합니다.

## 과제

1. 기본 `O/A 90일 고위험 수출` 시나리오를 엽니다.
2. 현재 거래 판정을 말합니다.
3. 가장 중요한 위험 3개를 찾습니다.
4. 우선 행동 3개를 말합니다.
5. 금융지원 상담 후보와 미확인 조건을 찾습니다.
6. 공식 데이터와 시스템이 확정하지 않는 내용을 설명합니다.

## 기록 항목

`data/usability_test_results_template.csv`를 복사해 작성합니다.

- 전체 완료시간과 판정 발견시간
- 위험·행동 정확도
- 금융지원 후보 이해도
- 데이터 경계 이해도
- 어려운 용어와 중복 화면
- 상담에 사용할 의향

실제 고객정보, 원본문서, 연락처, 계정정보는 기록하지 않습니다.

## 성공 기준

- 참여자 5명 이상
- 전체 완료시간 중앙값 180초 이하
- 판정 발견시간 중앙값 30초 이하
- 위험·행동 정확도 평균 각각 2.4/3 이상
- 데이터 경계 이해도 평균 4/5 이상

## 집계

완료 결과를 별도 파일에 저장한 뒤 다음을 실행합니다.

```powershell
Copy-Item data/usability_test_results_template.csv data/usability_test_results.csv
# 실제 익명 결과를 입력한 뒤
py -3.13 scripts/summarize_usability_results.py data/usability_test_results.csv --output outputs/usability_test_summary.json
```

결과 상태:

- `not_run`: 완료된 참여자 결과 없음
- `insufficient_participants`: 완료 결과가 5명 미만
- `needs_improvement`: 5명 이상이나 성공 기준 미달
- `meets_success_criteria`: 선언한 소규모 사용성 기준 충족

## 해석 경계

5명 편의표본은 제품 효과를 일반화하는 통계가 아닙니다. 참여자 배경, 날짜, 기기, 원자료와 실패 사례를 함께 보존해야 합니다. 결과가 좋지 않으면 숨기지 않고 어려운 용어와 중복 구역을 수정한 뒤 재검증합니다.
