# KB TradeGuard AI 사용성 검증 프로토콜

## 목적

공개 데모 사용자가 3분 안에 핵심 위험, 다음 행동, 금융지원 후보, 판단 근거를 찾을 수 있는지 확인합니다.

## 권장 참여자

- 중소기업 수출입 실무자 또는 경험자 2명
- 금융·무역·보험 관련 학습자 또는 실무자 2명
- 비전문 사용자 1명

현재 저장소는 참여자 결과를 임의 생성하지 않습니다. 실제 테스트를 수행한 뒤 아래 기록 양식에 입력합니다.

## 과제

1. 기본 시나리오를 엽니다.
2. 거래의 현재 판정을 말합니다.
3. 가장 중요한 위험 3개를 찾습니다.
4. 다음 행동 3개를 말합니다.
5. 우선 금융지원 상담 후보와 미확인 조건을 찾습니다.
6. 공식데이터가 무엇을 확정하지 않는지 설명합니다.

## 측정 항목

- 전체 완료시간(초)
- 판정 발견시간(초)
- 위험 3개 정확도(0~3)
- 행동 3개 정확도(0~3)
- 금융지원 후보 이해도(1~5)
- 데이터 경계 이해도(1~5)
- 이해하기 어려운 용어
- 불필요하거나 중복된 화면
- 상담에 사용할 의향(1~5)

## 성공 기준

- 중앙값 전체 완료시간 180초 이하
- 판정 발견시간 중앙값 30초 이하
- 위험·행동 정확도 평균 각각 2.4/3 이상
- 데이터 경계 이해도 평균 4/5 이상

## 주의

소규모 편의표본 결과는 제품 효과의 일반화된 통계가 아닙니다. 참여자 수, 배경, 날짜, 테스트 환경과 원자료를 함께 보존해야 합니다.
