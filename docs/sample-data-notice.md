# Sample-data notice

All bundled company, transaction, FX-rate, and demo-question data is synthetic
and exists only for competition demonstration and automated tests. It does not
represent an actual KB customer, account, quote, facility, approval, product,
or transaction.

Bundled demo mode loads only these files and disables document upload and
portfolio mutation. “Restore bundled sample state” removes session additions
and returns the demonstration to its initial synthetic state.
