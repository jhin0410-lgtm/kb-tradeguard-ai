# KB TradeGuard AI · 3분 최종 시연 스크립트

## 시연 URL

```text
https://<public-demo>/?presentation=1&scenario=oa_high_risk
```

공개 데모는 합성 거래를 사용하며 승인·법률의견·금리·한도·보험 인수를 확정하지 않습니다.

## 0:00–0:25 · 문제와 해결 방식

> 중소 수출입기업은 계약조건, 문서 불일치, 바이어·국가위험, 환노출과 운전자금 문제를 서로 다른 기관과 문서에서 확인합니다. KB TradeGuard AI는 이를 하나의 거래 단위로 결합해 거래 확정 전에 보완할 조건과 금융·보험·보증 상담 준비사항을 근거와 함께 제시합니다.

## 0:25–0:55 · 01 거래 판정

화면에서 현재 판정, 핵심 위험, 연결 근거 수와 우선 행동을 보여줍니다.

> 이 결과는 AI가 임의로 작성한 종합점수가 아닙니다. 검토된 입력을 5단계 결정론적 Pipeline에 넣어 `조건 보완 후 진행` 상태와 우선 Action Plan을 생성했습니다.

## 0:55–1:25 · 위험과 판단 근거

첫 번째 위험의 근거를 엽니다.

> 각 위험은 문서 Finding, 계산 ID, 공식 데이터 Snapshot과 연결됩니다. 누락정보는 추정하지 않고 추가 확인 항목으로 남기며 원본 Finding은 화면이나 AI가 변경하지 않습니다.

## 1:25–1:55 · 02 실제 시나리오 계산

FX 스트레스와 순노출 차트를 보여줍니다.

> 이 차트는 고정된 설명용 지수가 아니라 현재 승인 거래, 외화현금, 검토된 기준환율과 일정으로 다시 계산한 값입니다. 기준환율이나 결제일이 없으면 가짜 값을 만들지 않고 차트를 생략합니다.

## 1:55–2:25 · 03 금융지원·다음 행동

상위 상담 후보 3개를 보여줍니다.

> 상품 목록을 시나리오에 하드코딩하지 않았습니다. Decision Brief가 선택한 실제 ProductCandidate를 상태, 거래 목적, 공식 출처와 미확인 조건으로 정렬합니다. 결과는 승인이나 적격성 확정이 아니라 KB·K-SURE 상담 준비입니다.

## 2:25–2:50 · 04 검증과 감사

Rule·Gold Case·Mutation·대표 시나리오와 Case hash를 보여줍니다.

> 22개 Rule을 30개 Gold Case와 150개 의미보존 Mutation으로 회귀검증합니다. Hash는 동일 입력과 결과를 추적하기 위한 식별자이며 법률적 정확성이나 금융 승인을 인증하지 않습니다.

## 2:50–3:00 · 마무리

> KB TradeGuard AI의 차별점은 생성형 AI가 금융판단을 대신하는 것이 아닙니다. 결정론적 Rule·Calculation·Evidence와 제한된 AI 설명 계층을 연결해 고객과 상담직원이 더 준비된 상태로 무역금융 상담을 시작하도록 돕는 것입니다.

## 질의응답용 부록

일반 URL에서 `상세 분석·공식 데이터·AI 구조`를 열면 다음을 보여줄 수 있습니다.

- 다중 거래·다중 통화 포트폴리오
- World Bank·UN Comtrade 고정 공개데이터 사례
- 선택형 공식 API 조회
- AI·결정론 엔진·Human Review 역할 분리
- 전체 상품 Registry와 감사 산출물

## 발표 실패 대비

발표 전에 앱에서 `kb-tradeguard-competition-snapshot.html`을 내려받아 오프라인 사본을 준비합니다. 네트워크 장애 시 동일한 판정, 위험, 행동과 Case hash를 해당 파일에서 설명합니다.
