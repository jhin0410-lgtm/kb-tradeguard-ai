# KB TradeGuard AI · 3분 시연 스크립트

## 시연 원칙

- 공개 앱은 `competition_app.py` 또는 배포된 `streamlit_app.py`를 사용한다.
- 메인 시나리오는 `O/A 90일 고위험 수출`이며 첫 접속 시 자동 실행된다.
- 발표용 URL에는 `?presentation=1`을 사용한다.
- 판정은 승인·거절이 아니라 사전진단 상태라는 점을 유지한다.
- 핵심 주장은 `판단 근거 열기`와 Case hash로 추적한다.
- Live AI는 공개 공모전 앱에서 노출하지 않는다.

## 발표 URL

```text
https://<public-demo>/?presentation=1
```

모바일 체험용 QR은 일반 공개 화면에서 보여준다.

```text
https://<public-demo>/?demo=1
```

## 0:00–0:25 · 문제와 제품 정의

화면:

- 공개 Hero
- `핵심 위험 우선 / 판단 근거 / 검토 기록`

발표 문장:

> 중소 수출기업은 신규 해외 바이어와 거래할 때 계약서, 결제조건, 문서 불일치, 국가위험, 환노출과 선적 전 자금부담을 각각 따로 검토합니다. KB TradeGuard AI는 이를 `기업 × 거래 × 바이어 × 국가 × 계약조건` 단위로 결합해 거래 확정 전에 무엇을 보완하고 어떤 금융·보험·보증 상담을 준비해야 하는지 근거와 함께 제시합니다.

## 0:25–0:55 · 자동 실행된 거래 검토 요약

화면:

- 통합 판정 Banner
- 상위 위험·근거 ID·누락정보·Pipeline 지표
- 5단계 Trace

발표 문장:

> 공개 데모는 실제 고객정보가 아닌 검수된 합성 시나리오를 자동 실행합니다. 이 거래는 승인이나 거절이 아니라 `거래 확정 전 조건 보완 필요`로 분류됩니다. 문서 사전검사, 문서 정합성, 재무감내, 상담 후보, 통합 Brief가 동일한 결정론적 Pipeline으로 실행됩니다.

## 0:55–1:35 · 상위 위험과 판단 근거

화면 조작:

1. 첫 번째 위험 카드의 `판단 근거 열기`를 누른다.
2. 근거 ID, 원천 레코드, 기준일, 상태와 제한사항을 보여준다.

발표 문장:

> 시스템은 불투명한 종합점수를 만들지 않고 가장 중요한 위험을 순위화합니다. 위험 문장에는 근거 ID가 연결되고, 버튼을 열면 문서 조항, 계산 결과, 국가 정보, 바이어 정보와 기준일로 내려갈 수 있습니다. 원본 Finding과 Calculation은 UI가 변경하지 않습니다.

## 1:35–2:05 · 다음 실행 행동

화면:

- 다음 행동 3개
- 담당자, 상태, 선행 Action

발표 문장:

> 분석을 경고 목록으로 끝내지 않고 누가 무엇을 먼저 확인해야 다음 상담과 거래조건 협의가 가능한지 의존관계가 있는 Action Plan으로 변환합니다. 상품은 승인이나 적격성 확정이 아니라 상담 후보와 미확인 조건으로만 제시합니다.

## 2:05–2:30 · 검증 현황

일반 공개 화면으로 전환하거나 캡처 화면을 사용한다.

화면:

- 결정론적 Rule 22개
- Gold Case 30개
- 의미보존 Mutation 150개
- 대표 시나리오 4개

발표 문장:

> 룰 엔진은 22개 Rule 전체를 30개 명시적 Gold Case와 150개 의미보존 Mutation으로 회귀검증합니다. 이 수치는 합성 Fixture의 내부 일관성 검증이며 실제 거래의 법률적 정확성이나 금융기관 승인을 의미하지 않습니다.

## 2:30–2:48 · 감사 산출물

화면:

- Case hash
- 발표용 HTML 저장
- 감사 JSON 저장

발표 문장:

> 입력 Package, 입력 Case와 출력 Case의 hash를 보존하고 발표용 HTML과 감사 JSON을 제공합니다. Hash는 변경 추적 식별자이며 결과의 업무적 또는 법률적 정확성을 보증하는 인증서는 아닙니다.

## 2:48–3:00 · 모바일 연결과 마무리

화면:

- 공개 HTTPS QR
- 휴대폰의 `요약 | 근거 | 실행 | 감사` 하단 메뉴

마무리 문장:

> KB TradeGuard AI의 차별점은 AI가 금융 판단을 대신한다는 데 있지 않습니다. 결정론적 룰과 계산, 근거 ID, Human Review와 감사 가능한 산출물을 하나의 무역금융 업무흐름으로 연결해 중소기업이 은행과 보험기관에 더 준비된 상태로 상담하도록 돕는 데 있습니다.

## 발표 실패 대비

공개 네트워크가 불안정하면 앱에서 미리 다운로드한 다음 파일을 연다.

```text
kb-tradeguard-competition-snapshot.html
```

오프라인 HTML에도 상위 위험, 다음 행동과 Case hash가 포함된다.

8. 모바일 하단 고정 메뉴
9. Case hash와 Snapshot 다운로드

## 제출 시 표현

사용 가능:

- 결정론적 거래 사전진단
- 근거 기반 상담 준비
- 상담 후보
- 전문가 확인 선행 필요
- 거래 확정 전 조건 보완 필요
- 현재 검토자료상 중대한 경보 없음

사용 금지:

- KB 승인 완료
- 대출 가능 확정
- 보험 인수 확정
- 제재 해소 완료
- 안전한 거래 인증
- 법률적으로 유효함
- 실행 금리 또는 한도 보장
